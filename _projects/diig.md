A music discovery app that I built to improve the UX of browsing on various online record stores. It features iOS and Android apps with super responsive audio playback written in C++, and a [website](https://diig.app). Multiple custom scrapers written in python to extract data from my favourite record stores into a unified schema and a firebase database to store the information with scrapers running nightly on GitHub actions.

diig is currently invite only, with a small community of record diggers using it.
